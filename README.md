## Featured Projects

### 📊 Monitoring & Observability Platform
`Python` `Django` `Celery` `Celery Beat` `AWS SQS` `AWS SNS` `MS Teams Webhooks`

A scalable system that tracks API health and performance in near real time.

- Built asynchronous metric collection pipelines with **Celery and Celery Beat**, using scheduled execution and exponential backoff retries, which improved trend accuracy by **90%**
- Created real-time dashboards for uptime, latency, throughput and error rates, enabling faster root-cause analysis
- Integrated **AWS SQS, SNS and MS Teams webhooks** for instant failure alerts, cutting debugging and incident response time by **50%**
- Automated token refresh so monitoring continues uninterrupted when authentication tokens expire
- Added **role-based access control** to govern mutations on the monitored APIs

[🔗 View project](https://github.com/Saurabh1443/REPLACE-WITH-REPO-NAME)
